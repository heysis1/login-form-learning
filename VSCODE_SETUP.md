# Quick Start Guide for VS Code

## Step 1: Install VS Code Extension (if not already done)
1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X or Cmd+Shift+X)
3. Search for "Live Server"
4. Install by Ritwick Dey

## Step 2: Run the Project
1. Open this folder in VS Code
2. Right-click on `index.html`
3. Click "Open with Live Server"
4. Browser automatically opens at `http://localhost:5500`

## Step 3: Make Changes & See Live Updates
- Edit any file (HTML, CSS, or JS)
- Save (Ctrl+S or Cmd+S)
- Changes appear instantly in browser

## Step 4: Test the Form
1. Type a username/email
2. Type a password
3. Click "Log In"
4. See the captured data displayed

## Step 5: Open Developer Tools (F12)
- Console tab shows: JavaScript logs and errors
- Network tab shows: API requests (if any)
- Elements tab shows: HTML structure
- Sources tab shows: JavaScript debugging

## Troubleshooting

### Files not loading?
- Make sure all 3 files are in same folder:
  - index.html
  - styles.css
  - script.js

### Styles not showing?
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

### Form not working?
- Open Console (F12 → Console tab)
- Check for red error messages
- Try clearing browser cache

## File Sizes
